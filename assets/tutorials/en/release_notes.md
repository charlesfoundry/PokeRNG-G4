# Release Notes

## 1.0.7

### Clearer Seed Verification and Advance Guidance

Tap the seed you actually hit on this attempt:
- **If it is not the target seed**: return to Calibration with the actual Delay filled in. Tap "Apply Calibration" to update the timer.
- **If it is the target seed**: see the Chatot high/low pitch sequence and remaining advances to help you reach the target frame.

In HGSS, the app calibrates your current advance using the match and your recorded calls, so record every call result in the app.

In DP/Pt, coin flips verify the seed but cannot determine the current main RNG advance. If the environment has advanced the RNG, use a reverse search after catching a target to calibrate the Offset.
