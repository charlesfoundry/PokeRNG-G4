# DP御三家色違い

## 基本方針

DP 御三家乱数には、安定したコイントスやペラップ確認の手段がありません。

ライバル戦後に実際の能力値を読み取り、校準ページの逆算で次の情報を推定します。

- seed
- delay
- フレーム

## 場所の特徴

DP では **シンジ湖** で御三家を選びます。

プレイヤーは **201 番道路** で、自動イベントの発生まであと 1 歩の位置に立ってレポートします。

乱数調整中は、レポート読み込み後すぐ上方向キーを押し続け、最速でイベントを発生させます。

シンジ湖の冒頭イベントでは複数の NPC が動いて見えますが、これは固定されたイベント動作です。通常のランダム移動 NPC のように RNG を消費するものとして扱いません。

そのため、読み込み後すぐにイベントを発生させれば、目標は **第 0 フレーム** の御三家として扱います。

## 操作手順

1. 201 番道路で、自動イベント発生まであと 1 歩の位置に立ちます。
2. イベントを発生させる方向を向きます。
3. レポートします。
4. タイマーに従って DS 時間を設定し、ゲームを起動し、レポートを読み込みます。
5. レポート選択後、すぐ上方向キーを押し続けます。
6. 最速でシンジ湖イベントを発生させ、御三家を選びます。

目標検索では、フレーム範囲を固定します。

- 最小フレーム：0
- 最大フレーム：0

## 逆算

ライバル戦後、御三家の能力値を確認します。

校準ページの御三家逆算に次を入力します。

- ポケモン
- レベル
- 性格
- 能力値
- 個性
- 性別（結果を絞り込みたい場合）

最初の推奨範囲：

- フレーム範囲：0 から 0
- delay 範囲：±300

読み込み後すぐ上方向キーを押し続け、素早くイベントを発生させた場合は、第 0 フレームとして検索します。

## 校準

1. 逆算結果をタップします。
2. app が実際に命中した delay を入力します。
3. 結果を確認します。
4. 校準を適用します。
5. タイマーが更新されます。
6. 命中、能力確認、逆算、校準適用を繰り返します。

## 問題の判断

第 0 フレームの逆算で結果が出ない場合、まず次を確認します。

- ポケモン、レベル、性格、能力値、個性の入力が正しい。
- レポート読み込み後、すぐ上方向キーを押し続けた。
- レポート位置がイベント発生の 1 歩手前になっている。

入力が正しくても結果が出ない場合は、診断用に一時的にフレーム範囲を広げてもかまいません。通常の目標検索では、第 0 フレームを優先します。
