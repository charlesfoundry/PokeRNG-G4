# 更新内容

## 1.0.7

### Seed確認と乱数消費の案内を改善

今回、実際に命中したSeedをタップしてください：
- **目標Seedと一致しない場合**：調整ページに自動で戻り、実際のDelayが入力されます。「調整を反映」をタップするとタイマーが更新されます。
- **目標Seedと一致する場合**：ペラップの音程の高低と残り消費数が表示され、目標フレームまでの乱数消費を確認しながら進められます。

HGSSでは、検索結果と記録した電話回数から現在の消費数を補正するため、すべての電話結果をアプリに入力してください。

DP/PtのコイントスはSeedの確認に使いますが、メイン乱数の現在の消費数は特定できません。環境による消費がある場合は、捕獲後の逆検索でOffsetを補正してください。

### 更新内容とチュートリアルへの入口

- チュートリアル一覧の先頭に「更新内容」を追加し、いつでも確認できるようにしました。
- 各バージョンの初回起動時に、チュートリアル一覧を開いてから更新内容を表示します。自動表示は同じバージョンで一度だけです。
- 更新内容を閉じるとチュートリアル一覧に戻り、ほかのガイドを続けて読めます。
