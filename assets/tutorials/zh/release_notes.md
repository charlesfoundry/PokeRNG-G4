# 更新说明

## 1.0.7

### 更清楚的 Seed 确认与推进引导

点击选择这次实际命中的 Seed：
- **若未命中目标 Seed**：自动返回校准页并填入实际命中的 Delay，点击“应用校准”后更新定时器。
- **若命中目标 Seed**：显示聒噪鸟喋喋不休的高低音序列和剩余推进帧数，帮助你继续推进到目标帧。

HGSS 会根据匹配结果和已记录的电话次数校准当前帧，请在 App 内完整记录每次电话结果。

DP/Pt 的硬币用于确认 Seed，不能确定主乱数的当前帧；存在环境消耗时，仍需通过捕获后的反向查找校准 Offset。

### 更新说明与教程入口

- 教程页顶部新增“更新说明”，可随时回看。
- 每个版本首次启动时，自动进入教程列表，再打开更新说明；同一版本只自动打开一次。
- 关闭更新说明后，会回到教程列表，方便继续阅读其它教程。

## 此前更新

- 补充乱数入门与原理说明，新增 DP 初始乱数教程，更新 DP/Pt ID 乱数及 Pt 初始乱数教程。
- 完善优秀 SID 的筛选条件与结果展示，优化 ID 检索、年份传递及无结果提示。
- 统一定时器的操作体验；生成蛋与 ID 的长时间检索增加保持屏幕常亮功能。
- 整理设置页，更新 macOS 与 Web 图标。
