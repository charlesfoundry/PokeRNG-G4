# DP初始闪

## 核心思路

DP 初始乱数没有稳定的硬币或喋喋不休确认手段。

实际命中情况，需要在劲敌战结束后读取御三家的能力值，再用校准页的反向搜索推算：

- seed
- delay
- 帧

## 场景特点

DP 是在 **齐心湖** 内选择御三家。

玩家需要在 **201 号道路**，站在距离自动剧情触发只差 1 步的位置存档。

在乱数过程中，进入存档后，立刻按住上方向键不放，用最快速度触发剧情。

齐心湖初始剧情中会看到多名 NPC 移动，但这些移动属于固定脚本路线，不按普通随机 NPC 的移动来消耗 RNG。

因此，只要读档后立刻触发剧情，目标就按 **第 0 帧** 的初始宝可梦处理。

## 操作步骤

1. 在 201 号道路，移动到离自动剧情触发只差 1 步的位置。
2. 面向触发剧情的方向。
3. 存档。
4. 按定时器设置 DS 时间、启动游戏、进入存档。
5. 选择存档后，立刻按住上方向键不放。
6. 用最快速度触发齐心湖剧情并选择御三家。

检索目标时，建议将帧范围固定为：

- 最小帧：0
- 最大帧：0

## 反向查找

劲敌战结束后，查看御三家的能力值。

在校准页的御三家反向搜索中输入：

- 宝可梦
- 等级
- 性格
- 能力值
- 个性
- 性别（如果需要进一步缩小结果）

建议初始范围：

- 帧范围：0 到 0
- delay 范围：±300

如果读档后立即按住上方向键并快速触发剧情，正常应按第 0 帧查找。

## 校准

1. 点击反向搜索结果。
2. app 会填入实际命中的 delay。
3. 确认结果无误后，点击应用校准。
4. 定时器会刷新。
5. 重复命中、查看能力、反向搜索、应用校准。

## 判断问题

如果第 0 帧反查不到结果，优先检查：

- 宝可梦、等级、性格、能力值、个性是否输入正确。
- 是否在进入存档后立刻按住上方向键。
- 是否站在离剧情触发只差 1 步的位置。

如果输入无误但仍然找不到，可以临时扩大帧范围做诊断；但正式检索目标时，仍建议优先选择第 0 帧。
